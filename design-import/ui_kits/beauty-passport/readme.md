# Beauty Passport UI Kit
BeautyRoute's flagship differentiator — the client's "beauty medical file". Tabbed page: Overview (AI insights, allergies/medical, preferences), Beauty History (visit timeline), Hair History (formulas + bleaching/correction record), Gallery (before/after), Appointments (history + rebook), Payments (invoices, balance), Documents (consent forms). Private professional notes pinned at the bottom.

Composes: Tabs, Timeline, FormulaCard, ClientNotes, BeforeAfterGallery, AIInsightCard, ReviewSummary, Table, Badge, Button, RebookCard, FavoriteButton, EditorialImage.
