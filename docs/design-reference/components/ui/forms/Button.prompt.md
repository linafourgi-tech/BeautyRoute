Pill-shaped action button in four variants (primary charcoal, gold accent, secondary outline, ghost text) — use gold sparingly, for the single most important action on a screen.

```jsx
<Button variant="gold" size="lg">Book now</Button>
<Button variant="secondary">View portfolio</Button>
```

Variants: `primary` (default, high-emphasis neutral), `gold` (the one accent CTA per view), `secondary` (outlined), `ghost` (text-only, toolbars/cards). Sizes: `sm`/`md`/`lg`. Hover lifts 2px with a soft shadow; press is a 0.98 scale via the fast duration token.
